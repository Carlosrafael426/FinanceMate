## ✨ Funcionalidades

- ✅ Cadastro e login de usuários

- ✅ Autenticação JWT

- ✅ Criar, editar e excluir transações

- ✅ Visualizar receitas e despesas

- ✅ Relatórios financeiros

- ✅ Dark mode

- ✅ Design responsivo

## 🛠️ Tecnologias

### Frontend

- React 18

- Vite

- Tailwind CSS

- React Router DOM

### Backend

- Node.js

- Express.js

- MongoDB

- JWT (JSON Web Token)

- Bcrypt.js

### Deploy

- Frontend: Vercel

- Backend: Render

- Banco de dados: MongoDB Atlas

## 🚀 Como rodar localmente

### Pré-requisitos

- Node.js 18+

- MongoDB instalado ou conta no MongoDB Atlas

- Git

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/Carlosrafael426/FinanceMate.git
cd FinanceMate
```

### 2️⃣ Configurar variáveis de ambiente

- Frontend: copie `.env.example` para `.env` e ajuste `VITE_API_URL` se necessário
- Backend: copie `Backend/.env.example` para `Backend/.env` e defina `MONGODB_URI`, `JWT_SECRET` e `CORS_ORIGIN`
